# Proteus: playable build

▶ **[Play Proteus in your browser](https://juanivaldy.github.io/Proteus-demo/)**

Proteus is a systemic action RPG built by one developer directing four AI coding agents (Claude, Codex, Cursor, ChatGPT), each owning one area of the game. This repository hosts the single-file release build. The source is kept private.

- Levels 1–60, a 160+ node passive skill graph, 5 rarity tiers and 36 item base types with affixes
- Grafts and mutations, companion AI with tactics and progression, an encounter director, 6 bosses
- Animation-first combat on 3D skinned rigs, a 19-contract story campaign, procedural audio
- Built from ~30 source modules with byte-exact merge tooling and 200+ automated checks

Best in desktop Chrome. The first load is about 40 MB.
